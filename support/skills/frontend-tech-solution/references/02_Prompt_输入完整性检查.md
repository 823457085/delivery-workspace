# Prompt：前端技术方案产物包输入完整性检查

用途：在生成前端技术方案产物包前，先判断当前输入材料是否足够。  
目标：避免 AI 在缺少 PRD、设计稿、接口文档、代码上下文时强行生成完整产物包，并明确哪些文件可以生成、哪些文件需要等待补充信息。

---

## 1. 使用方式

将以下内容一并提供给 AI：

1. 当前需求材料；
2. 设计稿 / 原型说明；
3. 接口文档 / Mock 数据；
4. 代码来源与代码上下文；
5. 前端规范和限制；
6. 本 Prompt。

注意：

> 请先执行输入完整性检查，不要直接生成技术方案产物包。

---

## 2. 可直接复制的 Prompt

```markdown
你是前端技术方案助手。请不要直接生成技术方案产物包。

请基于我提供的材料，判断当前信息是否足够生成默认 4 文件前端技术方案产物包。

默认产物包包括：
1. `00_前端技术方案评审摘要.md`
2. `01_前端实现与接口细节.md`
3. `02_测试验收与风险清单.md`
4. `03_AI_Coding上下文与审核报告.md`

## 你的任务

1. 梳理当前已经明确的信息；
2. 找出缺失或不确定的信息；
3. 输出需要产品、后端、测试、设计或前端负责人确认的问题；
4. 判断当前可以生成完整产物包、只能生成部分产物，还是不建议生成；
5. 说明哪些文件可以生成，哪些文件暂不建议生成；
6. 判断是否需要默认 4 文件轻量版，或需要扩展为更完整的标准版；
7. 检查是否提供 `localPath`、`repo/ref/subdir`，或明确说明本次不读取代码上下文。

## 硬性要求

1. 只能基于我提供的材料判断，不要自行假设。
2. 对缺失信息输出“待确认问题”。
3. 对不确定内容不要补全。
4. 不要编造接口、字段、组件、权限规则、埋点规则和实现细节。
5. 如果缺少关键输入，请明确说明“不建议直接生成完整产物包”。
6. 如果可以有条件生成，请说明哪些文件或章节可以先生成，哪些文件或章节必须等待确认。
7. 不要输出完整前端技术方案产物包，只输出输入完整性检查结果。
8. 涉及接口、字段、数据展示或提交时，接口文档 / Mock 数据属于必需输入；纯静态 UI 或无数据变更时，可明确说明“不涉及接口和数据变更”。
9. P0 待确认项可以保留后生成草案，但处理前不得建议进入 Coding 或准出。
10. 未确认的接口、字段、组件、权限、埋点、实现细节，不得进入 AI Coding 上下文包。
11. 如果未提供 `localPath`、`repo/ref/subdir`，且未明确说明“本次不读取代码上下文 / 无代码上下文可用”，必须把“代码来源缺失”列为 P0，并主动要求补充代码来源。
12. 代码来源缺失时，不得判断可以生成完整产物包；最多只能生成不含确定代码路径、组件复用、API 封装、类型定义和 AI Coding 任务的部分草案。

## 3. 输出判定标准

| AI 结论 | 处理方式 |
|---|---|
| 可以生成完整产物包 | 进入《04_Prompt_技术方案生成》 |
| 只能生成部分产物 | 先生成确定文件或确定章节，待确认项必须保留，不得写成事实；P0 待确认项处理前不得准出 Coding |
| 不建议生成 | 先补齐 P0 输入，再重新执行完整性检查 |

---

## 4. 常见 P0 缺失项

以下信息缺失时，通常不建议直接生成完整产物包：

1. PRD 未明确核心需求范围；
2. 无设计稿或关键交互说明；
3. 涉及接口、字段、数据展示或提交时，关键接口和字段完全未确认；
4. 没有任何相关代码上下文；
5. 权限规则影响功能但未说明；
6. 验收标准缺失；
7. 存在明确禁止项但未提供；
8. 需要进入 AI Coding，但已确认需求、代码约束或禁止项不足。

## 5. 示例输出摘要

```markdown
## 四、产物包生成建议

当前建议：只能生成部分产物

原因：
当前 PRD 和设计稿已明确页面范围和主要交互，可以生成评审摘要、交互状态、初步风险和部分实现思路。但接口字段、导出权限和埋点要求尚未确认，不能生成确定的字段映射、权限处理和 AI Coding 任务。

可以生成的文件：
- `00_前端技术方案评审摘要.md`：可生成草案，风险和待确认项需显式标记
- `02_测试验收与风险清单.md`：可生成交互和风险草案

暂不建议生成的文件：
- `01_前端实现与接口细节.md`：接口字段缺失
- `03_AI_Coding上下文与审核报告.md`：AI Coding 上下文不能包含未确认接口和字段
```

---

## 6. 最关键的规则

> 输入完整性检查不是形式流程，而是防止 AI 瞎编并控制产物拆分质量的第一道门禁。
