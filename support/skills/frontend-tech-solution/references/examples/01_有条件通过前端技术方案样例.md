## 一、需求理解

### 1. 需求背景

运营同学需要定期导出筛选后的订单数据，用于线下对账和运营分析。目前只能逐页查看订单列表，人工整理成本较高。

### 2. 核心目标

在订单列表页增加“批量导出”入口，支持用户按照当前筛选条件导出订单数据。

### 3. 需求范围

- 在订单列表顶部操作区新增“导出”按钮；
- 点击导出后，基于当前筛选条件调用导出接口；
- 接口返回导出文件链接后，前端自动触发文件下载；
- 无数据时导出按钮置灰；
- 无导出权限时不展示导出按钮；
- 接口失败时展示错误提示。

### 4. 不做范围

- 不在本次需求中实现导出任务列表；
- 不新增导出文件下载页，导出文件由当前页面自动下载；
- 不调整订单列表现有筛选项。

### 5. 验收标准

- 有导出权限且列表有数据时，展示“导出”按钮；
- 点击导出按钮后，调用导出接口并传递当前筛选条件；
- 导出接口返回 `downloadUrl` 后，前端自动触发文件下载；
- 导出失败后展示错误提示；
- 无数据时导出按钮置灰；
- 无权限时不展示导出按钮。

## 三、实现方案

### 1. 页面结构

在订单列表顶部操作区新增导出按钮，位置位于现有“新建订单”按钮左侧。按钮状态受权限和列表数据影响。

### 2. 组件拆分

| 组件 | 职责 | 输入 | 输出 | 是否复用 |
|---|---|---|---|---|
| ExportButton | 展示导出按钮，处理点击导出 | `disabled`、`loading`、`onExport` | 点击事件 | 新增 |
| OrderFilterForm | 提供当前筛选条件 | 表单状态 | 查询参数 | 复用 |
| OrderListPage | 组合筛选、列表、导出逻辑 | 页面状态 | 页面渲染 | 修改 |

### 3. 数据流转

1. 用户在筛选区选择条件；
2. 页面维护当前查询参数；
3. 用户点击导出；
4. 前端将当前查询参数传给导出接口；
5. 接口返回 `downloadUrl`；
6. 前端创建临时下载链接并自动触发文件下载；
7. 接口失败或未返回下载链接时展示错误提示。

### 4. 状态管理

本需求不新增全局状态，仅使用订单列表页现有局部状态：

- 当前筛选条件；
- 当前列表数据数量；
- 导出请求 loading 状态。

### 5. 接口调用

导出按钮点击时调用导出接口。导出中按钮 loading，防止重复点击。接口成功返回 `downloadUrl` 后，前端自动触发浏览器下载。

### 6. 错误处理

- 接口成功且返回 `downloadUrl`：前端自动下载文件；
- 接口成功但未返回 `downloadUrl`：展示“导出失败，请稍后重试”；
- 接口失败：展示接口返回错误文案；无文案时展示“导出失败，请稍后重试”；
- 接口超时：展示通用错误提示。

## 四、接口与数据

### 1. 依赖接口

| 接口名称 | 方法 | 路径 | 用途 | 依据来源 |
|---|---|---|---|---|
| 导出订单列表文件 | POST | `/api/orders/export` | 按筛选条件生成导出文件并返回下载链接 | 接口文档 `export-order-list` |

### 2. 请求参数

| 参数 | 类型 | 是否必填 | 说明 | 来源 |
|---|---|---|---|---|
| status | string | 否 | 订单状态 | 接口文档 |
| startDate | string | 否 | 下单开始时间 | 接口文档 |
| endDate | string | 否 | 下单结束时间 | 接口文档 |
| keyword | string | 否 | 搜索关键词 | 接口文档 |

### 3. 返回字段

| 字段 | 类型 | 页面展示 / 使用位置 | 说明 | 来源 |
|---|---|---|---|---|
| downloadUrl | string | 自动下载 | 导出文件下载链接 | 接口文档 |

### 4. 异常返回处理

| 异常场景 | 前端处理方式 | 是否阻断流程 |
|---|---|---|
| 接口失败 | 展示错误提示 | 是 |
| 接口成功但未返回 `downloadUrl` | 展示通用错误提示，不触发下载 | 是 |
| 接口超时 | 展示通用错误提示 | 是 |
| 无权限 | 不展示按钮；若接口返回无权限则展示错误提示 | 是 |
| 空数据 | 按钮置灰，不调用接口 | 否 |
