# Artifacts

Artifacts define the standard outputs used by product, development, and QA teams.

| Directory | Purpose |
|-----------|---------|
| `artifacts/templates/` | Human-editable document templates |
| `schemas/` | Structured contracts for tools such as AI Delivery Hub and AI Delivery Gate Engine |
| `examples/` | Good and bad examples for training and review |

Templates are the source of truth for document structure. Prompts and skills should reference templates instead of embedding duplicate sections.
