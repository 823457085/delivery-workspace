# 自测证据规范

> 适用范围：开发自测报告、PR/MR 描述、G3 提测准入、GitLab Hook Review 和测试负责人抽查。

## 1. 目标

自测证据必须回答三个问题：

1. 测了什么，覆盖了哪些 AC/EX/NFR/TC。
2. 怎么测的，命令、环境、账号、数据和截图/日志在哪里。
3. 没测什么，风险、补偿措施和关闭时间是什么。

## 2. 证据类型

| 类型 | 要求 |
|------|------|
| 单元测试 | 命令、结果、CI 链接、覆盖率、测试文件/用例 |
| 接口测试 | curl/Postman/自动化脚本、请求响应、错误码 |
| 前端交互 | 截图/录屏、浏览器、关键状态、异常态 |
| 数据验证 | SQL、数据前后对比、抽样结果 |
| 日志/指标 | trace id、关键日志、监控截图 |
| 手工验证 | 操作步骤、账号/角色、环境、结论 |

## 3. G3 必填

| 项 | 要求 |
|----|------|
| P0 TC | MUST 100% 自测并有证据 |
| AC | MUST 每条有 Pass/Fail/N/A 结论 |
| 单测 | MUST 对照 `unit-test-standard.md` |
| 例外 | MUST 写原因、风险、补偿措施、Owner、关闭时间 |
| 证据链接 | SHOULD 使用可访问链接；本地临时截图不应作为长期唯一证据 |

## 4. 证据质量

不合格证据示例：

1. 只写“已测通过”，没有步骤和结果。
2. 只贴截图，没有说明对应 AC/TC。
3. 只提供命令，没有输出或 CI 链接。
4. 使用生产敏感数据、密钥、PII。
5. 证据无法被测试负责人或 AI 复核。

## 5. Review 判定

| 情况 | 默认级别 |
|------|----------|
| P0 TC 无证据或覆盖率不足 100% | blocker |
| Pass 无可复核证据 | blocker |
| 例外项无风险和关闭时间 | major |
| 证据与 AC/TC 映射不清 | major |
| 证据链接不可访问 | major |
