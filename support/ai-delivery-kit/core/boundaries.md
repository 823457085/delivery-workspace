# 08 · 边界测试目录（G2b 必查）

测试方案 Must 对本期功能逐项检查以下类别是否有 TC（或 PRD/EX 标注 N/A 且产品确认）：

| # | 类别 | 检查要点 | 最低用例意图 |
|---|------|----------|--------------|
| B1 | 等价类 | 有效/无效分区 | 至少各 1 类输入 |
| B2 | 边界值 | 0、1、min、max、max+1 | 数值/长度边界 |
| B3 | 空值 | null、""、缺字段、全空格 | EX-空值 |
| B4 | 长度/格式 | 超长、非法格式、特殊字符 | 与 PRD 字段约束一致 |
| B5 | 幂等/重复 | 双击、重复请求、重试 | EX-重复提交 |
| B6 | 权限 | 未登录、无权限、越权、角色差异 | EX-权限 |
| B7 | 并发 | 同时编辑、库存竞态 | EX-并发 |
| B8 | 超时/失败 | 下游 500、超时、部分成功 | EX-下游超时 |
| B9 | 数据态 | 不存在、已删、已过期、非法状态 | EX-数据不存在等 |
| B10 | 业务规则 | 额度、次数、时间窗、状态机 | PRD 业务规则 |
| B11 | 安全 | 注入、XSS（涉及输入展示时） | 按风险 |
| B12 | 兼容 | 端/版本/分辨率 | NFR-兼容 |
| B13 | 性能 | 响应时间、批量上限 | NFR-性能 |

## PRD EX 映射

test-plan-coverage-review Skill 审核时 Must 输出 B1–B13 覆盖表。
