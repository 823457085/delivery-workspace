# 10 · 效能指标

> 对齐 PDF §20；先 **4 周基线**，再评估 AI 改造效果。

---

## 10.1 过程指标（每迭代）

| 指标 | 计算 | 目标趋势 |
|------|------|----------|
| R1 驳回率 | 驳回次数/需求数 | 基线后下降 |
| G2 覆盖矩阵一次通过率 | 首次 G2 Pass/提审 | ↑ |
| G3 提测一次通过率 | 首次 G3 Pass/提测 | ≥60% 首迭代 |
| 预研 Q 在 G1 Close 率 | Closed Q/总 Q | 100% |
| PRD 覆盖 Gap 数 | 审计 | 0 |
| implementation-plan 先行率 | 有 implementation-plan 再提测的 Story 占比 | ≥90% |

## 10.2 AI 使用指标

| 指标 | 定义 | 90 天目标 |
|------|------|-----------|
| AI 活跃使用率 | 周使用企业 AI/Agent 的产研人员占比 | ≥80% |
| AI 参与需求占比 | 需求含 AI 留痕的比例 | ≥80% |
| AI 参与 PR 占比 | PR 含 pr-checklist 留痕 | ≥70% |
| Prompt 模板使用率 | 使用包内 prompts/Skill vs 自由问答 | ≥80% |

## 10.3 效率指标

| 指标 | 定义 |
|------|------|
| Lead Time | PRD Ready（R0 Pass）→ 上线 |
| 需求分析周期 | G0/G1 → R0 Pass（有上游时） |
| PR Review 时长 | PR 创建 → 合并 |
| 测试周期 | Code Ready → Test Ready |
| 返工次数 | PRD/设计/代码/测试返工 |

## 10.4 质量与业务指标

| 类别 | 指标 | 说明 |
|------|------|------|
| 质量 | 缺陷逃逸率 | AI 提效不得以质量下降为代价 |
| 质量 | Change Failure Rate | 发布失败/回滚/事故 |
| 质量 | AI 代码缺陷率 | AI PR vs 纯人工 PR 对比 |
| 业务 | 目标指标达成率 | G9 Outcome vs PRD §1/§3.5 |
| 业务 | Outcome Review 完成率 | 正式上线需求 ≥90%（90 天） |

## 10.5 首迭代预期

门禁变严后，短期 R1/G2 驳回可能上升；第二迭代起提测一次通过率应改善。

## 10.6 复盘机制

- 每周：试点团队门禁通过率、阻塞项  
- 每两周：抽查 5 个 AI 需求 + 5 个 AI PR 的留痕完整性  
- 每月：效率、质量、业务结果对比基线
