# Confluence 方案发布指引

面板任务只有同时包含已确认的 `designDestination` 与 `designPublicationAuthorized: true` 才执行。该授权标记仅由 `apply_jira_dev_requirement` 在 `confirmed: true` 时保存，读取或恢复计划不授权；`local`、`applied` 状态也不授权。本地计划同样须通过面板开始确认，仍不写 Jira。直接使用技能而没有面板任务时，须用户明确授权发布。本指引随插件提供，不要求另装技能；通过成员本人已批准的 Confluence 连接操作，不绑定作者账号，不复制凭据或读取浏览器 Cookie。

## 确认目的地与任务范围

新计划使用工作台中已确认的归档目录。每次发布前读取连接站点与父页，核对站点、空间、父页 ID 和标题；不因字段存在就宣称本次连接或权限已验证。目的地与计划不符时停止该写入，保留本地方案并继续独立工作。

旧计划缺少 `designDestination` 时不补填默认目的地、不自动迁移或发布。用户另行明确要求发布时，重新预览并确认具体目的地和本任务子页范围后再登记面板发布证据；不要手工伪造授权标记。没有面板任务标识时沿用明确授权范围，不伪造 `taskId`。

按来源 Jira、开发主任务和方案任务的实际编号搜索指定父页下的子页，并核对正文中的任务来源。找到唯一对应页面后，正文一致时直接复用；正文有新版且已授权更新时，用原页面 ID 和当前版本更新并回读。出现多项候选或归属不清时先核对。确认目录下没有对应页面且已授权创建时，才新建本任务的子页。

原方案位于其他父页时可保留为 `source`，核对内容后在已确认目的地下形成本任务子页，不移动或覆盖原方案。无已有本任务子页且创建范围已确认时，才创建新子页。

## 保存本地与保留完整 Markdown

发布前先完成本地保存，核对 `complete_jira_dev_technical_design` 返回的文件与 `sha256`。保存工具对输入 `body` 执行 `trim()`；必须读取最终保存的文件，以该文件的完整 UTF-8 内容作为发布正文与之后登记用的 `body`，不要对最初未经保存的输入计算摘要。文件内空白、表格、代码围栏和 Mermaid 均不改写。

使用 Confluence Storage 格式的 `markdown` 宏承载正文：

```xml
<ac:structured-macro ac:name="markdown"><ac:plain-text-body><![CDATA[完整 Markdown 正文]]></ac:plain-text-body></ac:structured-macro>
```

构造 Storage 正文时将 Markdown 中每个 `]]>` 替换为 `]]]]><![CDATA[>`，再放进外层 CDATA；回读时拼接文本后仍须得到完全相同的原 Markdown。不得将整份 Markdown 通用转换为 HTML/XHTML 后发布，也不把 Markdown 当作普通 HTML 文本提交。

使用连接提供的读取、搜索及创建/更新能力，实际字段以工具支持为准。工具不支持 Storage 正文、站点缺少 Markdown 宏能力、连接不可用或权限不足时，保留本地方案为待发布；不改用可能损失格式的转换方式，不申请或安装其他技能作为必经步骤。

## 回读后登记发布证据

写入返回后，重新读取页面及其直属父页，并读取 Storage 正文。核对页面 URL 的站点、空间、页面 ID、标题、版本、直属父页 ID 与父页标题；展开宏的正文必须与已保存文件逐字一致。仅 HTTP 成功、返回 page ID 或看到标题不足以证明已发布正确内容。

完成回读后，用同一 `taskId`、完整 `body`、`evidence` 和可选 `source` 再调用 `complete_jira_dev_technical_design`，增加可选 `publication`：

| 字段 | 记录内容 |
| --- | --- |
| `pageId` | 回读确认的实际页面 ID |
| `url` | 回读确认的页面 URL |
| `title` | 实际子页标题 |
| `parentId` | 回读确认的直属父页 ID |
| `spaceKey` | 回读确认的空间 key |
| `version` | 回读确认的页面版本 |
| `verifiedAt` | 本次回读完成时间，ISO 8601 格式 |
| `bodySha256` | 优先使用本地保存工具返回的 `sha256`，对应最终保存文件的完整 UTF-8 字节；不对原始未保存输入、Storage 包装或另行规范化的文本计算 |

`publication` 只是已完成发布的证据，不会执行 Confluence 写入。没有面板 `taskId` 时将同样证据保留在本地交接中。

写入超时或回读失败时明确“本地已保存，发布结果待核对”，保留已知页面 ID、URL 和请求结果，只读查找及回读，不盲目重试创建。页面存在但正文、父页或版本未核对一致时不填成功证据。恢复后先确认先前操作的结果，不能以新预览绕开未核对写入。

发布问题不阻塞独立的本地实现与验证。最终交接分别列明本地方案路径与已核验发布的 URL、版本、父页；尚未完成的发布保留准确原因。此流程不自动回写 Jira 方案链接、评论、状态、负责人或排期。
