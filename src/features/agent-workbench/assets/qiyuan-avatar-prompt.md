# 启元头像

生成方式：内置 image_gen。用户头像使用用户提供的原图，未编辑图片内容。

## 最终生成提示词

Use case: stylized-concept. Create one beautiful square avatar asset for an AI development assistant named 启元 (Qiyuan, the beginning/origin). A minimal luminous stellar core, a single elegant four-point star with soft rounded sculptural edges, pearl-white light at its center, subtle cyan and lavender iridescent glass highlights echoing a dark developer-workbench interface. Deep ink navy uniform background filling the entire square. Premium restrained 3D render, polished but warm, clean silhouette, no scattered particles, no busy space scene, no lettering, no symbols beyond the central star, no robot, no frame, no watermark. Composition: star centered, fills about 68% of canvas, generous balanced margin so rounded-square UI cropping preserves it. Strong legibility as a 32px chat avatar. Output one square image, not a mockup or a grid.
